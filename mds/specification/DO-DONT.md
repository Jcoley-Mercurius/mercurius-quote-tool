# Mercurius Quote Tool — Do / Don't

Version: MDS v1.0  
Status: Active

| Do | Don't |
| --- | --- |
| Use ink for structure and ordinary primary actions | Make every primary action green |
| Use green for trusted progression, verified success, acceptance, and paid state | Use green for neutral navigation, selection, or raw financial values |
| Use coral only for explicit AI generation or bounded AI emphasis | Use coral as a general promotional accent |
| Keep Marketplace/Direct source visible through quote lifecycle | Infer source from workspace, color, or URL alone |
| Preserve the exact supplied Mercurius identity asset | Redraw, approximate, replace, stretch, crop, or omit the logo |
| Pair status, source, urgency, price, and progress with visible text | Rely on color or icon alone |
| Reuse → compose → extend → create | Add a new one-off convention because it is faster |
| Use lifecycle status plus valid actions | Expose free-form lifecycle dropdowns |
| Use efficient desktop rows and labeled mobile cards | Force essential data into horizontal mobile scrolling |
| Move desktop summaries inline before mobile commitment actions | Hide price, source, expiry, or consequences in a drawer |
| Preserve work through validation, connectivity, and AI failures | Clear fields or restart the workflow after recoverable failure |
| Use geometry-matched loading and durable recovery feedback | Show a blank page or toast-only critical error |
| Distinguish coming-soon placeholders from loading, empty, permission, and error states | Imply a placeholder module is already functional |
| Omit unsupported trust, payment, protection, comparison, or competition claims | Invent product policy to complete a screen |
| Run responsive, accessibility, runtime, and visual-reference checks | Claim fidelity or compliance without evidence |
